# Connectly Roadmap

- [x] **Phase 0 – Scaffolding:** folder structure, config, landing/login/register/dashboard UI, Express + MongoDB + Socket.IO bootstrap
- [ ] **Phase 1 – Authentication:** register, login, JWT, `GET /auth/me`, protected routes, password hashing
- [ ] **Phase 2 – Users:** search users, profile update, avatar upload (Cloudinary)
- [ ] **Phase 3 – Conversations:** create/list one-to-one conversations, unread counts
- [ ] **Phase 4 – Messaging:** send/receive messages over REST + Socket.IO, history, pagination
- [ ] **Phase 5 – Presence:** online/offline status, typing indicators, read receipts
- [ ] **Phase 6 – Media:** image/file sharing
- [ ] **Phase 7 – Audio/Video calls:** WebRTC with Socket.IO signaling
- [ ] **Phase 8 – Hardening:** validation, rate limits, tests, logging
- [ ] **Phase 9 – Deployment:** env config, CI, hosting
